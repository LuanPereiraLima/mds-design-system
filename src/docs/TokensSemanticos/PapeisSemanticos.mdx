# Papéis Semânticos

Além dos papéis fixos de marca (`primary`, `secondary`...) descritos em
"Tokens Semânticos → Cores", o MDS oferece três **famílias de papel
reutilizáveis** — pensadas para componentes cuja função visual, não a marca,
é o que determina a cor: destaque visual (`visual`), retorno de sistema
(`feedback`) e base neutra (`neutral`). Os sufixos
`on`/`Container`/`Subtle`/`Muted` de cada família seguem o mesmo princípio de
posição e intenção já descrito na página de Cores — aqui aplicado ao papel da
família em vez de a um papel de marca fixo.

## As duas formas

Cada arquivo de papel gera duas formas no build (em
`src/tokens/css/semantics.css`):

- **Solta** — seletor `[data-<família>="<papel>"]`, com os nomes originais da
  família (`--visual`, `--on-visual`, `--visual-container`…). Serve a
  componentes que usam **uma família fixa** e só trocam o papel.
- **Agregada** — seletor `[data-semantic="<família>"]`, com as chaves
  renomeadas para `--semantic`, `--on-semantic`, `--semantic-container`…
  Serve a componentes **versáteis**, que trocam família *e* papel
  dinamicamente sem mudar o nome da variável que consomem.

As duas apontam para a mesma cor: a forma agregada é um alias da solta, que
por sua vez aliasa a cor da marca ativa. Combinando os dois atributos no
mesmo elemento (`data-visual="primary" data-semantic="visual"`), o
componente lê sempre `var(--semantic)` e o valor continua cascateando por
marca/modo.

Os grids abaixo aplicam esses seletores ao vivo — o swatch usa
`var(--visual)` (etc.) e o valor ao lado é a cor de marca resolvida.

export const cap = (s) => `${s[0].toUpperCase()}${s.slice(1)}`;
export const FIELDS = (fam) => [
  fam,
  `on${cap(fam)}`,
  `${fam}Container`,
  `on${cap(fam)}Container`,
  `${fam}Subtle`,
  `${fam}Muted`,
];
export const SEMANTIC_FIELDS = FIELDS('semantic');

export const FAMILIES = [
  { family: 'visual', roles: ['primary', 'secondary', 'tertiary', 'complementary'] },
  { family: 'feedback', roles: ['success', 'caution', 'critical', 'info'] },
  { family: 'neutral', roles: ['background', 'outline', 'surface'] },
];

export const Families = () => (
  <>
    {FAMILIES.map(({ family, roles }) => (
      <div key={family} style={{ marginBottom: 32 }}>
        <h2 style={{ textTransform: 'capitalize' }}>{family}</h2>
        {roles.map((role) => (
          <ColorGrid
            key={role}
            title={`${family}.${role} (forma solta)`}
            names={FIELDS(family)}
            attrs={{ [`data-${family}`]: role }}
          />
        ))}
        <p style={{ fontSize: 13, color: '#666' }}>
          Forma agregada equivalente: mesmos valores de <code>{family}.{roles[0]}</code>,
          lidos como <code>--semantic*</code>.
        </p>
        <ColorGrid
          title={`semantic.${family}.${roles[0]} (forma agregada, exemplo)`}
          names={SEMANTIC_FIELDS}
          attrs={{ [`data-${family}`]: roles[0], 'data-semantic': family }}
        />
      </div>
    ))}
  </>
);

<Families />
