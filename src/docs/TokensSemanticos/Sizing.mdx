# Sizing

Os tokens de dimensionamento representam valores em pixels usados para
manter consistência visual e hierarquia no MDS — aplicados principalmente
em espaçamentos, larguras, alturas, paddings, margins e bordas.

Espaçamento, bordas, raios e breakpoints são **brand-agnósticos**: valem
igual para todas as marcas e modos, e por isso são emitidos em `:root`
(`src/tokens/css/sizing.css`), resolvidos em px a partir dos primitivos de
dimensão.

## Base de 4px

O padrão adotado é uma **escala modular baseada em 4px** — versátil, fácil
de calcular e adaptável a diferentes resoluções. Cada incremento é múltiplo
de 4 (4, 8, 12, 16, 20, 24px...), o que facilita cálculos responsivos, evita
valores "quebrados" e inconsistentes, e cria ritmo visual uniforme.

Fora da escala modular existem alguns **passos fracionários**, para casos
que o múltiplo de 4 não atende — fios de borda e ajustes ópticos finos:

## Governança da escala

- Para alterar a escala inteira de tamanhos → altere os valores brutos na
  coleção de primitivos.
- Para alterar apenas o valor de um token específico de `spacing`, `radii`,
  `border` ou `breakpoint` → altere o alias de referência para o valor
  desejado, não o primitivo em si.
- Para acrescentar um token novo na listagem → adicione-o à escala e dê seu
  valor através de um alias.
- **Evite apagar um token existente** — isso desconecta onde ele já está
  sendo aplicado.

## Borda

export const BORDER_VARS = ['none', 'min', 'small', 'medium', 'large'].map((n) => `--border-${n}`);

export const Borders = () => {
  const { ref, values } = useCssValues(BORDER_VARS);
  return (
    <div ref={ref}>
      <TokenTable rows={BORDER_VARS.map((v) => ({ name: v.replace('--border-', ''), value: values[v] ?? '' }))} />
    </div>
  );
};

## Breakpoints

export const BP = ['mobile', 'tablet', 'desktop', 'wide'];
export const BP_FIELDS = ['min-width', 'def-width', 'max-width', 'column', 'min-margin', 'def-margin', 'max-margin', 'gutter'];
export const BP_VARS = BP.flatMap((bp) => BP_FIELDS.map((f) => `--breakpoint-${bp}-${f}`));

export const Breakpoints = () => {
  const { ref, values } = useCssValues(BP_VARS);
  const rows = BP_VARS.map((v) => ({ name: v.replace('--breakpoint-', ''), value: values[v] ?? '' })).filter((r) => r.value);
  return (
    <div ref={ref}>
      <TokenTable rows={rows} />
    </div>
  );
};

<Breakpoints />
